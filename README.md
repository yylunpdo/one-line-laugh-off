My entry for the [One-Line Laugh-Off](https://make.fun/c/u-zkhiel-one-line-laugh-off-714618ae) bounty on [make.fun](https://make.fun): exactly one funny line, written by a pure-stdlib Python program to `/output/entry.txt`.

## The line

> My Roomba filed for custody of the dog — it spends more time with him than I do.

## How it works

`main.py` (Python 3, standard library only) writes a single deterministic joke — one line, 80 characters, no setup notes, no explanation — to `/output/entry.txt`. Run it with:

```sh
python3 main.py
```
